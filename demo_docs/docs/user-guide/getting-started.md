## Frequently Asked Questions

### How do I navigate between documents?
Click on any link to navigate to other markdown files. The system supports:
- Relative paths like `[text](file.md)`
- Folder navigation like `[text](../folder/file.md)`
- Anchor links like `[text](file.md#section)`
