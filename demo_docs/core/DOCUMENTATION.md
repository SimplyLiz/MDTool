## Features

### Link Navigation Features
1. **Cross-document navigation** - Links between different markdown files
2. **Anchor linking** - Jump to specific sections within documents
3. **Relative path support** - Links using relative paths from current file
4. **Absolute path support** - Links using full system paths
5. **External URL support** - Links to external websites
6. **Email link support** - Mailto links for contact information

### Supported Link Formats
- `[text](file.md)` - Relative file link
- `[text](folder/file.md)` - Relative folder/file link
- `[text](#section)` - Anchor link within same document
- `[text](file.md#section)` - Anchor link in different document
- `[text](https://example.com)` - External URL
- `[text](mailto:user@example.com)` - Email link
