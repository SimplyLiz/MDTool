## What's MDTool?

MDTool is a cross-platform Markdown editor designed for both simple note-taking and professional document creation. Key highlights:

- **Native Performance**: Built with Flutter for smooth, responsive editing
- **AI Integration**: OpenAI and Ollama support for intelligent document assistance
- **Advanced Preview**: Real-time rendering with support for Mermaid diagrams and charts
- **Professional Tools**: PDF export, diff comparison, and multi-window support
- **Seamless Integration**: "Open with MDTool" support in macOS Finder and Windows Explorer
